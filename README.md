# Mahjong Mania

A table-side companion app for **American Mahjong**: a fast scorekeeper for experienced players and an on-demand coach for new ones. Built with Expo SDK 55.

> The app is being rebuilt from scratch. The full product and engineering plan, including research, rules, the hand notation, algorithms, UI, and the step-by-step implementation phases, is in **[docs/SPEC.md](docs/SPEC.md)**.

Not affiliated with the National Mah Jongg League.
