# Mahjong Mania

A table-side companion app for **American Mahjong** on iPhone: a fast scorekeeper for experienced players and an on-demand coach for new ones. It is built natively with Swift and SwiftUI and ships through TestFlight.

> The app is being rebuilt from scratch. The full product and engineering plan, including research, rules, the hand notation, algorithms, UI, the step-by-step implementation phases and the TestFlight release process, is in **[docs/SPEC.md](docs/SPEC.md)**.

Not affiliated with the National Mah Jongg League.
