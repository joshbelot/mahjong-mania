# Lesson prerequisites

The executable inventory is `CurriculumConcepts.requirements(for:)`. Tile-fact identifiers are defined by an exhaustive switch on `TileFacts.Fact`; the inventory reads each whole difficulty/focus pool, including all conditional house facts. The identifiers do not change question seeds or persisted exercise IDs. The table describes the teaching to review; it is not proof of comprehension.

| Concept or exercise family | First teaching | Human review |
|---|---|---|
| Suit/Dragon mapping, suit names, individual tile copy counts | Unit 1, Suits and dragons | Three numbered suits and aliases, four copies each, and three matching Dragons. |
| Flower, Joker, Soap, total set size | Unit 1, Flowers, jokers and Soap | Eight each, interchangeable individual Flowers, Joker group restrictions and Charleston, Soap as zero. |
| East's deal and first Charleston direction | Unit 1, Mixed | East 14, others 13; right, across, left. |
| Table-specific blanks, second Charleston, courtesy and Joker exchange | Hard tile-fact lesson, dynamically from selected rule book | Current selection is displayed, with blanks counted only when enabled. |
| Group names, counts, and Jokers in groups | Unit 2, Sets | Pair through Sextet and Joker as part of group. |
| Card line, suit-color relationships and number matching | Unit 2, Colours mean suits | Different printed colours denote different suits; hand must fit the full line. |
| Exposed and concealed | Unit 2, Exposed vs concealed | X versus C and calling last tile. |
| Recognising a completed hand | Unit 2, Which hand is this? | Compare the whole hand to the card. |
| Joker legality | Unit 1, Flowers, jokers and Soap; Unit 3, Is it legal? | Jokers require groups of at least three, never singles or pairs. |
| Distance and needed tile | Unit 4, Counting tiles away; What do I need? | N missing tiles and finding a tile that gets closer. |
| Choosing a hand | Unit 5, Follow your tiles | Prefer the hand using most of the rack. |
| Passing one or keeping/passing | Unit 6, Pass one; Keep or pass? | Keep helpful tiles and pass unneeded tiles. |
| Passing three | Unit 8, Three tiles | Select three together, using the closest hands. |
| Calling a discard | Unit 9, Call it? | Call for a group of at least three or to win. |

The automated inventory covers every exercise family at each lesson's actual difficulty and focus and also tests all family/difficulty combinations. Add new facts to the exhaustive mapping and new concepts to their current or an earlier teaching block. Checkpoints, test-outs and reviews assess material from earlier path teaching; ordinary lesson notes expose only the current lesson's teaching and never reveal the generated answer.
